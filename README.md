# ORAI Research Symposium 2026

Website for the ORAI Research Symposium (Thursday, December 3, 2026, Ginsburg Hall GCS 107, USC).

Live site: https://usc-orai.github.io/symposium/

## Editing

- The site is one file, `index.html`. All styles are in the `<style>` block at the top. Images are in `img/`.
- To make a quick change, open `index.html` on GitHub, click the pencil icon, edit, and commit. The live site updates within a minute or two.
- To add a headshot, upload it to `img/` and replace that panelist's initials `<div class="avatar" …>` with `<img class="avatar" src="img/FILE.jpg" alt="Name">`.

Program website: https://sites.google.com/usc.edu/usc-nrt-orai/home
